## 🛠️ Troubleshooting

### Frontend won't load?
- Check: http://localhost:5173 is accessible
- Check terminal 2 shows: "VITE ready"
- Refresh browser

### Can't register/login?
- Check: http://localhost:5000 is accessible
- Check backend shows: "✅ Server running"
- Check if both servers are running

### Data not saving?
- Check: `backend/data.json` has write permissions
- Check backend console for errors
- Restart backend: Stop & `npm run dev`

### Can't upload image?
- Backend must be running
- Image must be < 5MB
- Allowed formats: JPEG, PNG, GIF, WebP
